# 🛒 Wave Shop – E-Commerce Website 

Wave Shop is a modern, clean, and visually polished e-commerce website built using pure HTML and CSS. It features a smooth UI/UX experience, neatly structured product sections, and a responsive layout — perfect for showcasing your frontend skills in a portfolio.

## 🌟 Features

- Fully designed e-commerce homepage
- Modern gradient theme with smooth UI elements
- Sections for Special Offers, Featured Products, and New Arrivals
- Modern design & Responsive layout for all screen sizes

## 🧰 Tech Stack

- HTML
- CSS
